# CyberShield

Data broker monitoring platform. Monitor and remove your personal data from 70+ data brokers.

## Features
- **Flask backend** with API endpoints for brokers and security scans
- **Nginx or Apache** web server for serving the frontend
- **systemd service** running gunicorn
- **Unlimited-access admin** for giving certain email addresses unlimited subscription access

## Quick Install

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/blawson75/cybershield/main/install.sh)"
```

Or clone and run:
```bash
git clone https://github.com/blawson75/cybershield.git /opt/cybershield
sudo /opt/cybershield/install.sh
```

## Unlimited Access Admin

Use `admin.html` to grant unlimited subscription access to specific email addresses.

- Go to `http://your-server/admin.html`
- Enter your admin email and the token from `/etc/cybershield.env`
- Add/remove unlimited-access emails

Admin credentials are generated by `install.sh` and stored in `/etc/cybershield.env` (root-readable only).

## API Endpoints

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/api/brokers` | Public | List data brokers |
| POST | `/api/security/scan` | Public | Run a security scan |
| GET | `/api/subscription/check?email=` | Public | Check if email has unlimited access |
| GET | `/api/admin/whitelist` | Admin | List unlimited-access emails |
| POST | `/api/admin/whitelist` | Admin | Add unlimited-access email |
| DELETE | `/api/admin/whitelist?email=` | Admin | Remove unlimited-access email |

Admin auth uses headers: `X-Admin-Email` and `X-Admin-Token`.
